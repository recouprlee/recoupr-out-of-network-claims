# What outreach counts

Only totals are counted.

| Count | Where it is counted |
| --- | --- |
| Visits with the `ref` parameter | Site visit totals, grouped by `ref` value |
| Form fills by role | Site form totals, grouped by the role selected |
| Downloads by door | Download totals for the install line, ZIP or `SKILL.md`, paste-in prompt, and download page |
| Newsletter subscribers | The list tool's total subscriber count |
| Reported filings | The total number people choose to report after filing |

No names are included in any count. No count is joined to a person's claim or documents.
