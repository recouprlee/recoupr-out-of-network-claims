# Get the client handout

1. Open recoupr Out-of-Network Claims and choose the `client-handout` routine.
2. Give it the insurer, state, and public practice facts it requests.
3. Review the one-page handout before giving it to a client.
4. Or download the client handout from https://recoupr.ai/get-the-skill.
5. recoupr sends nothing, and the handout contains no client field.
