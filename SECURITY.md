# Security

recoupr Out-of-Network Claims is a set of Markdown instructions, reference files and three small Python scripts. It runs inside the AI assistant you choose and sends nothing to recoupr.

## Report a problem

Email howdy@recoupr.ai with the file, the line and what you observed. Please do not open a public issue for a security report, and please do not include any health information or anyone's personal details in the report.

We acknowledge reports within five business days. There is no bounty program.

## What counts

- A routine or reference that could lead an assistant to invent, change or sign something it must never touch (a code, date, fee, diagnosis, provider detail, signature).
- A script that mishandles its input.
- Any personal data or health information found in the repository, its history, or a release.
- A release artifact that does not match the tagged source.

## Out of scope

The AI assistant you run the skill in is a separate product with its own security program. Insurer websites, forms and portals belong to the insurers.
